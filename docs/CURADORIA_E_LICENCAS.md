# Política de curadoria

Os registros em `curadoria/` são sínteses e adaptações originais fundamentadas em material de campanha fornecido pelo autor do projeto. Não constituem transcrição das fichas oficiais de D&D de livros proprietários.

- Não importar automaticamente o livro comercial de Dungeon World para este repositório; os exemplos de instinto/movimentos são escritos para a Carcaça.
- Para regras, cite o Dungeon World SRD e a `Divisória do Mestre` CC BY 3.0 quando usada; os elementos conceituais podem ser adaptados com crédito e observância da licença aplicável.
- As fichas de terceiros continuam em `dist/creatures` com licença por fonte.
- `curadoria/` não é reescrito pelo importador. O código de geração só publica `dist/`.
- Não publicar narrativas de campanha privadas sem autorização explícita; este projeto já está público e as criaturas piloto foram resumidas para indexação, não reproduzidas na íntegra.
